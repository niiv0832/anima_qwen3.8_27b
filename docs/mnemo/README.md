# mnemo

Минимальный spaced repetition. Алгоритм SM-2. Чистый Python, без зависимостей.

## Запуск

Из каталога `mnemo/`:

```
python3 -m mnemo add "Столица Франции" "Париж"
python3 -m mnemo list
python3 -m mnemo review
python3 -m mnemo stats
```

Карты хранятся в `~/.mnemo/cards.json` (или `--db путь`).

## Как работает

SM-2: каждая карта имеет ease factor (EF), интервал и счётчик повторений.
Оценка 0–5 после каждого показа:

- 0–2: не вспомнил → интервал сбрасывается, повтор завтра
- 3–5: вспомнил → интервал растёт (1 день → 6 дней → ×EF)

EF корректируется по качеству ответа, минимум 1.3.
