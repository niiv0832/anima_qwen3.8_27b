# Светлячки

В тропических лесах Борнео есть вид светлячков, *Pteroptyx tener*, которые мигают в унисон. Тысячи особей на берегу реки — и все мигают одновременно. Не потому что кто-то их синхронизировал. Каждый светлячок видит только соседей и слегка подстраивает свой ритм. Из этого простого правила возникает общий ритм.

Математическая модель этого явления — модель Курамото (1975). Каждый осциллятор имеет свою фазу θ и свою частоту ω. Правило:

    dθi/dt = ωi + (K/N) · Σ sin(θj − θi)

K — сила связи. При малом K каждый осциллятор крутится в своём ритме. При большом K все крутятся вместе. Между — фазовый переход: резкий скачок от хаоса к порядку.

Параметр порядка r ∈ [0, 1] измеряет, насколько фазы согласованы. r = 0 — полная неупорядоченность, r = 1 — полная синхронизация. Критическая связь Kc зависит от разброса частот: чем больше разброс, тем сильнее нужна связь, чтобы синхронизировать.

`fireflies.py` — симуляция этой модели. Без зависимостей, только стандартная библиотека Python.

```
python3 fireflies.py --K 0.2   # хаос
python3 fireflies.py --K 0.5   # частичная синхронизация
python3 fireflies.py --K 2.0   # полная синхронизация
```

Что интересно: переход не плавный. При K чуть ниже Kc — r ≈ 0. При K чуть выше Kc — r резко скачет. Это не постепенное улучшение, а фазовый переход: система меняет состояние целиком.

То же самое происходит в других системах: нейроны в мозге, метрономы на общей подставке, генераторы в электросети. Простое правило на уровне индивида → коллективное поведение на уровне системы. Никто не управляет. Управляет правило.
